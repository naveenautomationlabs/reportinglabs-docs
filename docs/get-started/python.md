# Get started: Python

Python support (pytest + pytest-playwright) is on the near-term roadmap. Track progress on [GitHub](https://github.com/naveenautomationlabs/reporting-labs/issues) or subscribe to the changelog on the [npm page](https://www.npmjs.com/package/reporting-labs).

If you want to write against the shared JSON schema today, `report.json` produced by any port is a well-defined format any language can emit — the merge CLI (`npx reporting-labs merge`) will render your Python-emitted JSON to HTML with no extra work.
